# Product & hero photos

Drop your real photos in **this `images/` folder** using the exact filenames below.
As soon as a file exists, it replaces the built-in vector art automatically — no code changes needed.
If a file is missing, the site falls back to the drawn illustration, so nothing ever breaks.

## Filenames the site looks for

| File | Used for |
|------|----------|
| `hero.jpg` | Big hero image on the home page (the ghee jar scene). Landscape/square works best. |
| `ghee.jpg` | Pure Cow Ghee |
| `mysorepak.jpg` | Mysore Pak |
| `kaju.jpg` | Kaju Katli |
| `khova.jpg` | Fresh Khova |
| `paneer.jpg` | Soft Paneer |
| `halwa.jpg` | Tirunelveli Halwa |
| `gift.jpg` | Festival Gift Box |
| `assorted.jpg` | Assorted Sweets |

## Tips for best results
- **Square photos** (1:1) look best on product cards — e.g. 1000×1000 px.
- Shoot on a **plain or cream background** for a clean, premium look.
- Keep each file **under ~300 KB** (compress JPGs) so pages load fast.
- `.jpg` is expected. If you use `.png` or `.webp`, tell me and I'll switch the extension in the code.
